# 03 · 场景手册

按**工作场景**整理 PersonalAgent 的真实用法。每个场景给 3 条左右能马上照做的 tips，并配一手案例。

同一个场景，管理者和执行者都会遇到，只是用法不同。所以每个场景都会同时写 🧑‍💼 管理者视角和 🧑‍💻 执行者视角。

## 已上线

### 00 · 把 Agent 引入工作

所有场景的前提：哪些事交出去、怎么放权、规矩怎么定。

**3 条 tips**

1. **先盘点两周，只交"按规则就能做"的事。** 把每天的工作分成"按规则就能做的"和"需要判断的"，人事、法务、重大财务、声誉相关的始终留给人。
2. **按四周节奏放权。** 第 1 周看着它跑 → 第 2 周全部审核 → 第 3 周只审它标记的 → 第 4 周变成定时任务；权限按"只读 → 起草 → 发送"逐步放开。[^rafy]
3. **同一个账号下的多个 Bot，不要当成安全隔离。** Grok Bot 同一用户的所有 Bot 共用一台电脑和全部登录，不是权限边界；敏感数据要靠"不接入"来保护。[^cp]

**管理者补充**：员工可能已经用个人订阅把公司系统接进了 Agent，绕过了公司的安全审查。先摸清现状，再决定统一采购还是放任。[^beam]

**实操案例** → [案例 01 · 让一个 bot 替你管一整支队](案例01-一个bot管一整支队/README.md)
Grok Bot 工程负责人 Lauren Tan 的做法：四个角色、四步搭建、规矩写死、按风险分级自动合并。
