# 01 · 信息与情报

> 最后验证：2026-11-03 ｜ 适用：Grok Bot、Dots（定时任务）｜ 国内可用性：待作者实测 ｜ 状态：初稿

早上打开手机，几十个群、上百条推送，你真正要看的可能只有三条。**这个场景要做的，就是让 Agent 在固定时间给你一份短简报：只放和你有关的几条，每条都附来源。**

**典型任务**：每日简报、行业和竞品监控、会议和直播笔记、核实传闻

| | 怎么用 |
|---|---|
| 🧑‍💼 管理者 | 一份早报看清今天该关注什么：日程、要跟进的事、行业里和公司有关的动态 |
| 🧑‍💻 执行者 | 盯住自己负责的客户、竞品、项目动态，出了变化第一时间知道 |

**推荐产品**：Grok Bot（能排定时任务，关掉 App 也照常跑）｜备选：Dots

## Tips

1. **固定时间推送，不要实时打扰。** 例如每天 8:00 和 17:00 各汇报一次：公司动态、没跟进的待办、会议资料。一天两次，比随时弹消息更让人愿意看。[^s01-josh]
2. **限定条数，并要求附来源。** "只要和【我的公司/赛道】相关的 3 条，附来源"，比"帮我关注行业新闻"有用得多。条数一限，它就得替你做取舍；附了来源，你才能点开核对。（作者建议，见下方模板）
3. **核实传闻时，让它把结果分成四类。** 官方已确认 / 当事人说过但官方未确认 / 媒体和用户转述 / 没有证据。这样你一眼就知道哪些能转发，哪些只能听听。[^s01-zhihu]

## 一键复制

以下提示词均为作者原创，CC0，可直接复制、修改。把【】里的内容换成你自己的。

| 你的情况 | 用哪条 |
|---|---|
| 第一次试，想 1 分钟上手 | ① 极简版 |
| 管团队，想要一份每日早报 | ② 每日简报（管理者） |
| 只关心自己负责的客户、竞品、项目 | ③ 盯住我负责的对象（执行者） |
| 不需要每天看，一周看一次就够 | ④ 每周行业 / 竞品周报 |
| 有一场会议或直播要补课 | ⑤ 会议 / 直播笔记 |
| 群里传了一条消息，不知道真假 | ⑥ 核实一条传闻 |
| 不知道该让它关注什么 | ⑦ 先问我，再帮我配置 |

**① 极简版**

```
每个工作日早上 8:00，给我 3 条和【我的行业】有关的新消息，每条 1 句话，附原始链接。没有值得报的就说"今天无重要变化"。
```

**② 每日简报（管理者）**

```
你是我的情报助理。每个工作日 8:00 和 17:00 各给我一份简报，每份不超过 300 字：
1. 公司动态：和【我的公司】直接相关的新消息，最多 3 条
2. 行业动态：只要和【我的赛道】相关的 3 条，每条 1 句话说明为什么和我有关
3. 没跟进的待办：我答应过别人、但还没完成的事
4. 今天会议要用的资料：每个会附 1 句背景
规则：
- 每条都附原始链接；找不到来源的不要写
- 拿不准的标【待确认】
- 没有值得报的就写"今天无重要变化"，不要凑数
- 只读，不替我对外发任何消息
```

<details>
<summary><b>③ 盯住我负责的对象（执行者）</b></summary>

```
帮我盯住下面这些对象：【客户 A、竞品 B、项目 C】。
每个工作日 17:00 汇报一次，只报"和昨天相比有变化"的内容：
- 每个对象最多 2 条，每条附原始链接
- 每条后面写 1 句：这件事可能影响我手上的哪项工作
- 没有变化的对象写一行"无变化"即可
```

</details>

<details>
<summary><b>④ 每周行业 / 竞品周报</b></summary>

```
每周一 9:00，给我一份上周的【行业 / 竞品】周报，用表格：
| 对象 | 上周发生了什么 | 对我们意味着什么 | 来源链接 |
要求：
- 竞品只看【竞品 A、B、C】，每家最多 3 条
- 最后加一段"值得我这周跟进的 1 件事"，写明理由
- 没有来源的不写；拿不准的标【待确认】
```

</details>

<details>
<summary><b>⑤ 会议 / 直播笔记</b></summary>

```
这是一场【会议 / 直播】的【录像链接 / 逐字稿】：【粘贴】
帮我整理成笔记：
1. 一句话总结：这场讲了什么
2. 要点：最多 5 条，每条附时间点（例如 12:30）
3. 原话：最值得引用的 3 句，保留原文，附时间点
4. 和我有关的：哪些内容可能影响【我的工作 / 我的公司】
5. 待办：如果有人提到要做的事，列出谁、做什么、什么时候
听不清或不确定的地方标【待确认】，不要补全。
```

> 能不能直接"看"直播或视频，各产品不一样，以实测为准；拿不准时，先给它逐字稿。

</details>

<details>
<summary><b>⑥ 核实一条传闻</b></summary>

四类分法来自知乎《全网最全 Grok 使用指南》[^s01-zhihu]。

```
帮我核实这条消息：【粘贴原文或链接】
把你找到的信息分成四类，每类列出来源链接：
1. 官方已确认
2. 当事人说过，但官方未确认
3. 媒体和用户转述
4. 没有证据
最后用一句话告诉我：这条消息现在能不能当成事实转发。
```

</details>

<details>
<summary><b>⑦ 先问我，再帮我配置</b></summary>

```
我想让你每天帮我盯信息，但还没想清楚要盯什么。
先问我 5 个问题，弄清楚：我的角色、我最关心的公司和人、我常看的信息来源、我希望什么时间收到、每次最多看几条。
问完后，帮我写一份每日简报的规则，给我确认；我说"可以"之后再排进定时任务。
```

</details>

## 要设置的审批点

- 这个场景**只需要只读权限**：读邮件、读日历、读网页。不要为了一份简报给它发送权限
- 简报里提到要回复、要转发的，它只列出来，由你决定

## 翻车提醒

- **来源也可能是编的。** 头几周每天随手点开一两条链接核对；发现编造来源，在规则里加一句"链接打不开的不算来源"。（作者建议）
- **转述当成了事实。** 二手消息最容易混进简报，这就是 Tip 3 要分四类的原因。
- **国内信息源能不能读到，待实测。** 公众号文章、微信群、需要登录的行业网站，海外产品不一定能读取。（待作者实测）
